# Portfolio Notice

This public repository is an **Engineering Evidence / Technical Case Study** for **Scout**.

It is intentionally not a mirror of the private production source repository. The public artifact exists to make the following reviewable:

- product thesis and commercial workflow;
- system architecture;
- scoring logic and decision boundaries;
- market-adaptation model;
- operational controls;
- testing/verification scope;
- known limitations;
- evidence status for important claims.

Production source, credentials, operational infrastructure details, and proprietary implementation remain private.

## Evidence language

Claims in this repository are written using explicit evidence boundaries such as:

- `IMPLEMENTED`
- `TESTED`
- `VERIFIED IN A CONTROLLED RUN`
- `DEPLOYED`
- `MEASURED`
- `ESTIMATED`
- `SCAFFOLDED`
- `PLANNED`
- `NOT YET VALIDATED`

The strongest claim should never exceed the strongest evidence available.

## Market scope

Turkey is the reference market for the industrial-discovery configuration described in this case study. It is not claimed that Turkish market signals or scoring weights transfer unchanged to other countries. The reusable asset is the architecture; each new market requires local source, taxonomy, scoring, language, compliance, and commercial validation.
