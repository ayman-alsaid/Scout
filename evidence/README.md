# Scout — Evidence Index

This folder indexes the main evidence boundaries used by the public case study.

## Implemented / documented evidence

- shared discovery pipeline serving multiple commercial arms;
- deterministic Quality Score and Priority Score;
- Turkish industrial reference configuration across 81 provinces;
- international Web Opportunities configuration across 51 countries / 5 regions;
- SSE discovery flow;
- approximately 30 API endpoints;
- scheduler, analytics, outreach queue, deals pipeline;
- six AI-provider management paths;
- 8-language interface with Arabic RTL in the supplied project record;
- governed outreach lifecycle;
- JWT/bcrypt authentication model.

## Explicit non-claims

The repository does not convert the following into evidence without sufficient outcome data:

- closed-deal prediction accuracy;
- email deliverability benchmark;
- response/conversion uplift;
- universal portability of Turkey-specific scoring weights;
- successful commercial validation in every country;
- successful pilot in every adjacent domain researched in the content library.

## Market-portability evidence boundary

The current system demonstrates two different geographic scopes inside one platform: a Turkish industrial reference configuration and a broader 51-country Web Opportunities configuration. This supports the architectural claim that geography is not inherently fixed to one country.

It does not by itself prove that every data source and scoring factor works equally well in every country. New markets require adapter-level validation.

## Claim → Evidence principle

For each important public claim, reviewers should be able to identify:

1. the claim;
2. its evidence status;
3. the supporting architectural or controlled-run record;
4. its scope;
5. what the evidence does **not** prove.

That boundary is part of the portfolio, not a disclaimer added afterward.
